# Messiah — Tenor Study

Self-contained HTML page for practicing the tenor solos and recitatives from Handel's *Messiah* (HWV 56).

## Use

1. Open [`messiah_tenor_study.html`](./messiah_tenor_study.html) in Chrome (or any Chromium browser), or use GitHub Pages if enabled.
2. Choose a tenor movement.
3. Press **Play**, then slow the **Playback speed** slider (down to 0.25×) while learning the line.
4. Tenor is synthesized clearly; accompaniment is muffled. Adjust levels if you want.

MIDI sequences are embedded public-domain Bot Productions / Schirmer-based files. No external script libraries.
